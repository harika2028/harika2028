## 👩‍💻 About Me

I'm **Niharika Yarasu**, an Electronics & Communication Engineering graduate interested in **VLSI, semiconductor technology, digital electronics and practical engineering systems**.

My hands-on work includes **CMOS and transistor-level concepts, digital circuit design, VLSI implementation, embedded systems and IoT**. I enjoy understanding how a system moves from logic and architecture toward circuit-level implementation and real-world operation.

I'm also exploring **cybersecurity and network security** while continuing to strengthen my electronics and semiconductor fundamentals.

## 🚀 Featured Projects

### ⚙️ Hybrid Parallel Prefix Adder
**Han-Carlson + Ladner-Fischer Architecture**

A VLSI design project exploring a hybrid parallel-prefix adder using **CMOS and advanced GDI techniques**.

**Highlights**
- 32-bit hybrid architecture
- CMOS, PTL, DPTL, GDI, MGDI & FSGDI implementations
- DSCH schematic design
- Microwind layout and verification
- 32 nm technology analysis
- Power comparison across implementation techniques

**Repository:** [View Project →](https://github.com/harika2028)

---

### 🌱 Touch-Me-Not Crop Protection System

An embedded/IoT-based agricultural system inspired by the defensive response of *Mimosa pudica*.

**Highlights**
- Intrusion detection and alerting
- Soil-moisture-based irrigation
- Solar panel tracking using LDRs and servo control
- Wi-Fi/cloud monitoring
- Renewable-energy-oriented design

**Repository:** [View Project →](https://github.com/harika2028)
